- Discount analysis.

- Business insights and decision-making recommendations.

**Daily Deliverables:**

- KPI structure preparation.

## 🔐 Data and Privacy

- Large datasets should be linked to their original sources whenever possible.
- Do not upload confidential or restricted datasets.
- Never commit passwords, API keys, or private credentials.
- Maintain a `README.md` inside each data folder explaining the dataset source and download instructions.
- Include only data that is permitted for academic and project use.
